# 参考照片与构图：先把人认对，再安排座位

本页用于生成前的输入登记、身份提取、尺度和站位。默认每个场景直接生成一张成图；不先制造一张“标准脸”再反复转手。

## 输入各司其职

实际查看每张输入，记录文件、角色和本次是否使用。提交图像工具时，顺序为：**主环境 → 本次指定的身份参考 → 可选服装参考**。使用多张同一人的照片时逐一列明，不能暗中混入历史成图或未指定的人脸。

| 角色 | 可以提供 | 不能顺手带入 |
|---|---|---|
| 主环境 | 画布、机位、FOV、背景布局、原环境光色、真实物件 | 原有人物的身份；画作描绘内容中的虚构灯光和空间 |
| 身份参考 | 脸型、五官相对比例、自然肤色、年龄感、发型及辨识特征 | 自拍房间、原照色偏、原照光向、耳机或手机等偶然道具 |
| 可选服装参考 | 指定衣物、材质、身体比例的可见线索 | 替换人物身份、来源场景、来源打光、未要求的道具 |

服装默认用文本描述，避免为了拿一件衬衫顺便拿错一张脸。多张身份图确实提供互补角度时可以共同使用，但在记录中说明每张承担的线索；互相矛盾的发色、表情或色偏不强行平均。

把身份与拍摄条件分开：保留自然面部饱满度、眼鼻唇和下颌比例，不瘦脸、漂白、磨皮。过近自拍的透视、眯眼或夸张表情不能一概当成永久解剖结构；也不能借此重做五官。需要改变表情时写清目标表情，保留可辨识比例。

## 锁定原环境视角

标记至少一个清楚可见的稳定锚点，优先窗框交点、画框四角、桌边、墙地交线、栏杆或路径边缘。提示词要求这些锚点在原画面坐标附近保持；保持原焦距/FOV的视觉关系，不缩放、拉宽或重新搭建背景来迁就人物。

用户明确允许时才扩展外围。扩边保持原图核心区域的投影关系，不能把扩边当成更换广角镜头。只有视觉证据时写“保持原FOV印象”，不编造毫米数或已经完成相机标定。

## 先定尺度，再分析人物受光

依次决定：

1. 人物站/坐在哪里，前后有哪些真实物件，哪个面提供支撑。
2. 参照家具、门框等多项线索，选择协调的头肩、躯干和道具占比；分开检查人物是否突出、身体内部比例、人物相对环境的深度尺度。
3. 写清身体/手/道具之间的遮挡、桌面对下半身的遮挡，以及画外裁切。
4. 确定位置后再落实光源与接收面关系；灯光师不负责偷偷搬椅子。

大画作比近处人物大，单凭这一点不能判定透视错误。参照物尺寸没有实测时使用宽范围假设，并标明是创作选择。画中人物不能作真人尺。只露半身时，可见躯干高度不等于完整身高；脚在画外就记录地面接触无法验证，不补造一双脚来凑验收。

调整占比时同步处理头、肩、手、身体与相机等随身物件；不要只放大脸。生成模型可能重绘姿态，检查结果是否协调，不宣称已经做了像素级严格等比缩放。

## 可选离线尺度规划

通常将定性结论直接填入生成简报即可。需要保存可复查的尺度计划时，使用 `scripts/plan_scene_scale.py`。它只读取EXIF转正后的画布大小、检查声明并计算条件范围，不识物、不测深、不验证落地。

```text
python scripts/plan_scene_scale.py --input /workspace/run/scale.json --out-dir /workspace/run/scale-plan-new
```

定性输入的完整最小形状见 [schemas.md](schemas.md#尺度计划)。只有参照物尺寸、完整站立高度、光轴深度比和投影近似均有明确声明时，才选 `bounded_projection`。明显俯仰、前倾、端点深度变化或畸变无法处理时使用 `qualitative_only`。

近似关系为 `h人物/h参照 ≈ (H人物/H参照) × (Z参照/Z人物)`。`Z` 是相机光轴深度，与闪光源到人的距离不是同一变量。没有现场尺度时，这只是约束构图的假设，不能包装成三维重建。
