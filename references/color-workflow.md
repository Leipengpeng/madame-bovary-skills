# 可选工具追色：可以调色，别把灯调没了

**默认直接交付生图结果，不自动追色。** 用户明确要贴近原环境的曝光/色彩，或任务已有指定的工具调色基线时，才进入本分支；先保留未调色输入。追色处理全图颜色映射，不生成阴影、修复身份或重建光向。

## 新场景先建立自己的颜色映射

使用原环境和本场景的未调色成图，实际查看后标注：

- `exclude_boxes`：旧/新人像、接触阴影、遮挡变化和重构物件的并集。
- `skin_boxes`：实际可见脸、手臂等皮肤，尽量不含背景；它们是检查区，不是精细分割。
- `audit_regions`：未遮挡、稳定且有代表性的墙面、天空、木材或其他背景区域。

框为EXIF转正后的归一化 `[x0,y0,x1,y1]`。模板坐标不能原封不动套在新照片上。新场景不借用其他场景的LUT；每张图的装修师傅都不一样。

```text
python scripts/match_scene_tone.py --config /workspace/baseline/config.json
```

将 [配置模板](../examples/grade_config.template.json) 改成实际路径与区域后，另存到新的基线目录，文件名使用 **`config.json`**。需要Python、Pillow、NumPy、OpenCV，脚本不接外部服务；输出落在配置目录并拒绝覆盖输入/已有结果。无ICC时按sRGB处理并披露，有ICC时先转换。

追色脚本在该目录写入 `grading_report.json`，不会替你复制或重命名配置。后续冻结脚本固定读取报告旁的 `config.json`；因此原配置、报告、报告引用的未调色输入、获选成图和可选LUT必须保留且路径有效。若原配置用了其他文件名，在冻结前将**同一原配置原样**保存为报告同目录的 `config.json`，不能用重写的检查区冒充原基线配置；新候选的区域变化用单独的 `candidate-regions.json`。

脚本先检查背景几何与覆盖，画幅或背景移动过大就停止，不变形图片来掩盖问题。随后对稳定背景拟合有界单调亮度曲线、小幅共享色度变换，必要时比较带约束的33³ Lab残差LUT。候选均从同一未调色图计算，不累计叠加；拟合/选参验证块分开，但选参块不是完全独立测试。

保存报告、所选精确变换、输入/输出哈希并实际看同尺寸对照。统计改进仍须服从皮肤、暗部、局部物件的视觉检查；灰白/青色皮肤、端点截断、断层或暗部损失应拒绝。脚本阈值不能为迁就某张图临时降低。

## 同场景修订冻结一次

已有本场景获选映射，随后修改人物尺度或闪光时，固定原参数，避免重新拟合把刚加的光照和投影“追回去”。从新的未调色成图一次应用原精确变换：

```text
python scripts/apply_frozen_grade.py --input /workspace/run/revised-raw.png --report /workspace/baseline/grading_report.json --report-sha256 FROZEN_REPORT_SHA256 --scene-id scene --candidate-regions /workspace/run/candidate-regions.json --output /workspace/run/revised-graded-new.png
```

命令中的 `FROZEN_REPORT_SHA256` 替换为选定基线时记录的报告SHA256；若使用冻结合同，取其保存的原报告哈希。**参数曲线/色度分支必须提供 `--report-sha256`**，LUT分支也支持此检查；不能在报告改变后重算一个哈希来绕过冻结。输出必须为新的PNG，输出父目录须预先存在，脚本不会创建该目录。

人物位置变化后必须按新图重标 `candidate-regions.json`。它包含非空 `exclude_boxes`、`skin_boxes` 和 `audit_regions`；几何检查排除旧/新区域并集，皮肤和审计使用新框。省略此参数仅适用于确认人物及检查区仍在原位置的情况。

脚本核对原输入回放、报告/变换哈希、几何和保护约束。获选的是参数曲线/色度变换就冻结精确参数；获选的是LUT就冻结完整LUT，不换成近似版本，不重复叠加，不重新拟合。检查失败时保留未调色图和失败原因，不能绕过保护强出“最终图”。

## 结束条件与记录

最多两次新的拟合尝试，连续无改善、达到上限或剩余缺陷超出调色能力就停止。直接预览图、工具调色候选、冻结参数修订图分别命名，不混称同一流程。最终审图必须看实际交付文件并绑定它的哈希。

报告中的L*分位、色度偏移、ΔE和端点比例是显示图像统计，不是物理EV、品牌手机ISP标定或身份准确率。错向照明、缺失反光、错误投影和磨皮仍需生成阶段解决；调暗一点不能让悬空的人自动落地。
