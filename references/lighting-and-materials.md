# 光源、阴影与反光：闪光灯也要讲道理

用于主环境分析、手机直闪简报和生成后查错。默认在同一次图像生成中完成人物入景与指定闪光，不自动多做一套环境光版本。

## 原环境光先交代清楚

查看真实灯具、窗户、同一物体的受光与投影、多处中性表面。每项写 **观察 → 推断 → 把握 → 未知**，多个物件的证据互相支持时才提高把握。深色材质不是自动等于阴影，暖墙也可能来自墙漆或白平衡。

每个候选光源分开记录：

| 维度 | 内容 |
|---|---|
| 几何类型 | `point_like / area / directional / unknown`；依据人物处的相对角尺寸，不能只看灯具名称 |
| 传播方式 | `direct / diffuse_bounce / mixed / unknown`；直达光与墙顶反射填充分开 |
| 作用 | `key / fill / ambient / unknown`；最亮的灯不一定是人物主光 |
| 方向 | 图像左/右/上/下，加相对相机前后关系；二维影子不足以恢复完整坐标 |
| 光色 | 相对冷暖或偏色、依据及材质/白平衡混淆；未测量就不报精确色温 |
| 光质与依据 | 表观大小、软硬的条件、证据ID及 `low / medium / high` 把握 |

面光源可以直接照射形成软影，小灯经大墙反射也可形成柔和填充。镜面高光不代表全场只有点光源。画作中描绘的灯、人物、地板不能建立现场光照；真实画布和画框则能受光、遮挡、反光。

这些分析解释的是背景已经记录的照明，只用来让新增人物适应。不能因为分析出射灯，就在原墙上再画一次亮斑。

## 把光源落实到材料

分别写脸颈、手臂、头发、衣料、随身物件的操作。脸与手来自同一套光场；暗衣、浅色印花、金属和皮肤有不同响应，不能全图统一提亮冒充打光。印花是反射率变化，不是光斑；肩带与衣领要有贴合关系。保留原环境曝光、白平衡和远景反差，避免额外HDR、棚拍柔光箱、大片泛光和影视调色。

## 直闪是新增光，不是整张照片的曝光旋钮

用户要求时启用 `direct_phone_flash`；默认创作设定为镜头附近、略高且偏图像右的一枚小型手机闪光，具体强弱服从用户。写明这是设定，不是从图片测出的灯位。

近处可达的皮肤、衣料、桌面、杯具和金属都可能响应；前景、人物、近背景、远背景分别分析。远处城市、天空、河面保留环境光；不要让一枚手机灯跨江承包夜景照明。

固定环境曝光与白平衡时，提示词采用“原环境受光 + 可达的新增闪光贡献”。阴影只遮挡相应光源的贡献；被挡住的闪光接收区仍保留环境照明，不能刷成比原环境更黑的大剪影。闪光可以填淡原环境阴影，保持的是几何关联，不是强行锁死原对比度。

## 三项必须分别写出的细节

### 1. 前景—人物—背景的阴影链

每条记录 `光源 → 遮挡物 → 真实接收面`，再写方向、软硬、贴合和可见性。

- 前景手臂/杯底 → 桌面：从真实接触附近开始，短投影方向与同一闪光一致。
- 人物 → 近墙/椅背/实心窗框：必须确有接收面，不能把透明窗后夜景当成墙。
- 鼻/眼镜/下巴 → 脸/颈：属于人物自己的短阴影。

可见性用 `visible / mostly_occluded / off_frame / uncertain`。近轴身体投影可能藏在人物后，只露少量影边；不为“效果明显”强行搬出巨型黑影。影子不要求跨越到每一层，脚在画外也不要求看到脚影。

### 2. 镜面表面与反射路径

先清点真实存在的眼镜、相机镜头、玻璃杯、窗玻璃、餐具或抛光金属。没有某物就不添加。对每项写材质、所在区域、朝向及 **光源 → 表面 → 拍摄相机** 的可能路径，结论可以是可见、有条件、不可见或未知。

表面方向允许时出现小亮点或窄亮条；眼镜需保留双眼可读性，玻璃保留透明度，镜头保留镀膜和曲面响应。不要在两片眼镜、镜头和每只杯子中央盖同一个白点，也不加星芒、眩光、无关逆光来冒充反射。

### 3. 面部局部短阴影

检查鼻翼/鼻下、下唇下方、下巴到颈部、镜框到面颊、发际到额头，以及衣领贴合。小光源产生的局部遮挡应沿同一设定方向，保留环境填充。直闪整体偏平可以合理，局部结构仍不能被磨成一张发光面膜；也不能为了显影偷偷增加一盏侧灯。

## 距离只在有依据时算数

通常使用定性关系。若有明确的近轴、共线、平行参考面假设，可用 `scripts/plan_light_transport.py` 对距离区间做简化推导：

```text
python scripts/plan_light_transport.py --input /workspace/run/flash-geometry.json --output /workspace/run/flash-estimate-new.json
```

令光源到人物为 `a`、人物到接收面为 `b`、有效发光尺寸为 `D`，条件公式为：接收面距离 `a+b`，新增闪光照度比约 `(a/(a+b))²`，墙面物理投影倍率约 `1+b/a`，单边半影过渡宽度约 `D*b/a`。照度比还要求小角尺寸直达光、相近入射角、光强分布与无遮挡；不是整图像素亮度比。

投影倍率不能乘照片中的人物像素大小，半影宽度不是高斯模糊半径。人与墙近时影子可小且较清楚；人物靠近闪光并不自动推出“大而模糊”。脚本的 `Dmax/a_min ≤ 0.1` 是保守使用门槛，不是精度保证。反射闪、大面源或复杂遮挡使用定性模式，详见 [schemas.md](schemas.md#闪光距离计划)。

## 从计划到执行

默认直接生成使用 `scripts/compile_scene_brief.py`；其完整输入模板见 [../examples/direct_scene_brief.template.json](../examples/direct_scene_brief.template.json)。必须先查看实际图片，再替换模板的场景证据、区域框和操作，检查输出 `image_prompt.txt`，按输出参考顺序提交内建图像工具。编译器没有调用图像模型，也没有证明文字在物理上正确。

单独局部受光修订且已有冻结追色基线时，可使用 `scripts/compile_lighting_contract.py` 的schema 4；这是可选分支，不能强制套到默认直出流程。所有模式生成后都按 [review-and-stability.md](review-and-stability.md) 实际审图。

物理约束的参考依据：[PBRT 点光源](https://pbr-book.org/4ed/Light_Sources/Point_Lights)、[PBRT 镜面反射与透射](https://pbr-book.org/4ed/Reflection_Models/Specular_Reflection_and_Transmission)、[Nikon 闪光基础](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/the-basics-of-flash-photography)。这些说明光源、材料与拍摄的基本关系，不证明生成图经过了物理渲染或现场标定。
