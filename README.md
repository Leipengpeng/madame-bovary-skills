# 名媛型男 Skills

*Madame Bovary · 包法利夫人*

**行李还没收，旅行写真先有了。**

不一定要先飞到某个地方，才能拥有一组以那里为背景的旅行写真。给一张自拍和一张环境参考图，让AI把你放进想去的风景：街边咖啡、海边落日、美术馆里的片刻停留。精致亮丽的生活，也可以先从一张图开始创作。

你负责挑风景、想穿搭，这个Skill负责把人、透视、光线和阴影安排明白。人在沙发上，几何也得正常上班。

成图属于**AI合成写真**。它尽量保留人物辨识度、环境视角与光色，按需加入自然手机直闪，再认真审图，让这趟想象中的出发自然好看。也支持日常场景入景、指定换装，以及“换张自拍会不会突然换个人”的稳定性测试。

## 它会做什么

| 任务 | 具体做法 |
| --- | --- |
| 保留人物辨识度 | 指定身份参考；隔离自拍色偏、近摄畸变和临时道具 |
| 把人放进参考环境 | 保留环境画幅、FOV、透视锚点，先定尺度、落点和遮挡 |
| 对齐环境光 | 从真实表面和阴影提取证据，区分推断与未知 |
| 手机直闪 | 分析近景/人物/远景响应，补真实接收面上的阴影、条件成立的反光和面部短阴影 |
| 审查贴图感 | 实际看成图，给主观融合参考分及扣分原因，单列闪光是否到位 |
| 检查换自拍的稳定性 | 同设置逐张单参考出图，保留首轮结果，不暗中挑片 |
| 按需追色 | 用对应背景区域统计原环境光色，再做有记录的固定变换 |

名媛、型男是照片的审美方向。它不会从长相鉴定存款，也不会因为穿了黑衬衫就顺便给你颁发董事长任命书。

## 固定下来的默认流程

**看原图 → 分配参考角色 → 规划尺度/遮挡 → 分析环境光 → 按需加入手机闪光 → 一次直接生图 → 实际审图评分 → 必要时一次重点修订 → 交付。**

默认每个环境一张，单张身份参考，不自动追色、不强制无闪光中间图。用户明确提供多张同人照片共同约束身份时支持多参考；用户要求测试不同自拍时，每次只用其中一张。

拍摄感来自可信的光、材质、构图和细节，不靠撒噪点、拉爆高光或一键电影滤镜。“像手机拍的”也可以清楚、好看。

完整约定见 [WORKFLOW.md](WORKFLOW.md)，模型实际执行入口见 [SKILL.md](SKILL.md)。

## 安装

仓库目录本身就是一个Skill。宿主需要支持本地Skill、图片查看，以及图像生成/编辑；只有Python无法生成照片。分析与审图由宿主GPT完成，图像生成由宿主可用的内建图像工具完成。没有额外模型账号、API密钥或自动上传服务。

将仓库克隆到本地Skill目录；下面以Codex默认目录为例。若设置了 `CODEX_HOME`，放到它的 `skills` 子目录。已有同名目录时先检查，不要覆盖。

```bash
git clone https://github.com/Leipengpeng/madame-bovary-skills.git ~/.codex/skills/madame-bovary-skills
```

也可以从 [版本下载页](https://github.com/Leipengpeng/madame-bovary-skills/releases/tag/v1.0.1) 下载附件 `madame-bovary-skills-v1.0.1.zip`，解压后将其中的 `madame-bovary-skills` 文件夹放进宿主的Skill目录。若下载的是GitHub自动生成的源码ZIP，解压目录可能带 `-main` 或版本后缀，请改为 `madame-bovary-skills`。确保目录结构为 `madame-bovary-skills/SKILL.md`，别套成两层同名文件夹。

旧版用户请将新版作为独立目录安装，并停用旧版Skill，避免宿主同时发现两份规则。此版本统一了品牌、调用名和使用说明；制作流程与离线算法沿用已验证版本。

安装后确认宿主能识别该Skill；没有出现时，按宿主说明刷新技能或重新打开会话。然后在具备图片查看和图像生成/编辑能力的会话中调用：

```text
使用 $madame-bovary-skills。
图一是环境，图二是我的身份参考。
把我自然地放进环境里，保留原视角和背景光色，做手机直闪，先生成一张。
```

只做普通入景时，直接说“不加额外闪光”；换装时补充衣服描述。工作资料建议放在Skill目录之外，原图可以躺着，别让它们跟着代码出远门。

## 第一次用，照这四步

**普通用户只需要上传图片、说清要求。下面的Python命令和JSON模板都是可选工具，不是开拍前的入学考试。** 安装Skill提供的是工作规则，宿主本身仍需能看图并调用图像生成/编辑工具。

1. **确认技能已可调用。** 在宿主中能找到“名媛型男 Skills”，或能识别 `$madame-bovary-skills`。
2. **上传至少两张图。** 一张清晰的人像，一张想进入的环境；上传顺序可以调整，但请写明每张图的角色。可以直接发在当前对话里；支持本地文件的宿主也可以使用它能读取的图片路径。照片不用提交到这个GitHub仓库。
3. **复制请求，先做一张。** 姿势、穿搭和闪光都是可选描述；想保留原衣服就明说，想要直闪就加“手机直闪”，没有要求闪光时匹配环境光。
4. **查看图片与审图结果。** 默认每个环境一张照片，附0–100的主观融合参考分、主要不足；闪光任务另说明是否达到要求。需要修改时指出具体位置，例如“下巴阴影偏弱”“人物相对椅子太小”。原图和首稿会保留。

```text
使用 $madame-bovary-skills。
图一是环境，图二是我的人像。
请把我自然地放进去，保留环境视角和光色，先出一张。
衣服保持原样，不加额外闪光；姿势请按场景合理安排。
请交付成图、融合参考分和最主要的问题。
```

**多图时说清是哪种任务：**

| 你想做的事 | 可以这样说 | 默认数量 |
| --- | --- | --- |
| 一个人进入多个环境 | “用这张自拍，分别放进这三个环境，每个环境独立出图。” | 3张 |
| 多张同人自拍共同参考 | “这两张是同一个人，请共同参考，分别放进三个环境。” | 3张 |
| 比较不同自拍是否稳定 | “这两张自拍分别测试三个环境，每次只用其中一张自拍，保留首稿。” | 6张首稿 |

多个环境默认分别生成，只有明确要求合并环境时才另做合并规划。联合参考和逐张测试是两种任务，不能把联合参考的结果拿来充当单张自拍的稳定性证明。

如果助手提示缺少图片，补齐人像或环境；如果提示找不到Skill，检查安装目录和技能发现状态；如果宿主没有图像工具，只能交付待执行简报，不能生成照片。融合参考分属于主观审图意见，不是照片真实概率。

## 三种常用请求

**普通入景**

```text
用这张人像和这张环境图做一张自然手机照片。
保持环境机位、视角和光色。人物坐在空椅子上，穿深色短袖，不加闪光。
```

**手机直闪**

```text
把指定人物放进这个室内场景，直接生成手机直闪效果。
保留环境曝光。先考虑前景物件、人物与后景的距离，
再处理桌面投影、眼镜/玻璃反光、鼻下和下巴短阴影。
给一个融合参考分和主要问题。
```

**不同自拍稳定性**

```text
这三张都是同一个人的不同自拍。
固定环境、站位、服装和闪光设置，每张自拍独立生成一张。
每次只用该张自拍，保留首轮结果，比较脸型、发色、表情和配件是否漂移。
```

多参考联合生成请明确说“这几张是同一人，请共同参考”；这与逐张稳定性实验是两种任务。

## 开发者与可选离线工具

普通对话出图不要求用户自己运行这些命令。需要自行编译简报、辅助计算、追色或验证工具链时，再安装依赖：

```bash
python -m pip install -r requirements.txt
```

只想先验证工具链，可生成一组完全虚构的线条/色块输入，再编译：

```bash
python examples/make_smoke_fixture.py --out-dir /absolute/path/new-fixture
python scripts/compile_scene_brief.py --brief /absolute/path/new-fixture/direct_scene_brief.json --out-dir /absolute/path/new-compiled
python -m unittest discover -s tests -v
```

Windows请把示例绝对路径换成实际路径并加引号。生成的 `image_prompt.txt` 是给图像工具的简报，`compiled_brief.json` 记录输入顺序与哈希。**上述命令不会生成照片**；合成线条通过测试，也不代表真人合成已经通过审美验收。

只有自行运行离线编译器时，才需要复制 [简报模板](examples/direct_scene_brief.template.json)，替换实际文件路径，并根据看图结果重写所有环境相关字段。普通用户直接在对话中提供照片与要求，由助手组织简报即可。模板里的桌子不是任何场景都能用的万能家具。

| 工具 | 用途 |
| --- | --- |
| `compile_scene_brief.py` | 当前默认直出简报的校验与编译 |
| `plan_scene_scale.py` | 有依据的尺度、深度和裁切辅助计算 |
| `plan_light_transport.py` | 明示假设下的闪光距离、投影和半影估计 |
| `score_fusion_review.py` | 汇总人工填写的视觉审图项，不会自动看图 |
| `match_scene_tone.py` | 按需统计对应背景区域，选择并记录追色变换 |
| `apply_frozen_grade.py` | 把已记录变换复放到未调色输入，并检查保护条件 |
| `compile_lighting_contract.py` | 已有合成图的几何锁定受光修订，接固定追色分支 |

字段、前提和命令详见 [schemas.md](references/schemas.md)；颜色分支详见 [color-workflow.md](references/color-workflow.md)。

## 效果与边界

本版冻结的是已经迭代过的工作方法和数值工具。保留FOV、光照分层、真实阴影接收面、反光路径与面部短阴影等关键约束；图像模型更新、自拍角度、原照色偏和遮挡仍可能影响结果。

融合参考分是GPT的主观视觉评分，不是“有多少概率真拍过”，也不表示身份稳定性已量化认证。镜头不是测量仪，单张图的深度与灯位通常存在多解。明显换脸、错误投影或比例问题会单独报告，高分不能把它们盖住。

Skill源码目录和安装ZIP不含真人照片、私人环境图或历史成图的图片文件。本页通过GitHub附件链接展示用户授权的三张示范图，仅作主页效果展示，不作为Skill内置参考，也不进入安装包。内置的线条与色块样例用于验证离线工具链；验证记录见 [VALIDATION.md](VALIDATION.md)，输入与发布边界见 [PRIVACY.md](PRIVACY.md)。
